# 인생 메이커 (4단계)

하루를 일기로 기록하면 AI 기록관이 판정해서 스탯과 스킬 숙련도를 올려 주는 자기계발 기록 게임.

## 실행

`index.html`을 더블클릭하면 크롬이나 엣지에서 열린다. 서버도 설치도 필요 없다.

- 기록은 그 브라우저 안에만 저장된다. 브라우저 데이터를 지우거나 기기를 바꾸면 사라지니 **설정(오른쪽 위 톱니바퀴) → 백업 파일 저장**을 주기적으로 해 둘 것.
- 다른 브라우저나 다른 기기로 옮길 때도 백업 파일 저장 → 새 곳에서 불러오기.

## 화면

| 탭 | 내용 |
|---|---|
| 오늘 | 일지 쓰기, 오늘의 판정, 오늘의 퀘스트 요약 |
| 기록 | 날짜별 지난 일지 |
| 퀘스트 | 보유 포인트, 집중 목표, 일일·주간·월간 퀘스트, 뽑기 |
| 보관함 | 훈장·업적·칭호, 뽑은 아이템과 조각 교환 |
| 캐릭터 | 내 방 꾸미기, 스탯, 스킬, 성장 규칙 |
| ⚙ 설정 | AI 연결, 하루 기준 시각, 백업. 톱니바퀴를 다시 누르거나 "돌아가기"로 원래 탭으로 |

휴대폰·브라우저의 뒤로 가기 버튼도 앱 안에서 동작한다. 창이 열려 있으면 창을 닫고, 아니면 이전 탭으로 간다. 보고 있는 탭을 다시 누르면 맨 위로 올라간다.

## AI 연결 (설정)

| 선택 | 필요한 것 | 비용 |
|---|---|---|
| 직접 판정 | 없음 | 0원. 활동·강도·스탯을 직접 고르고, 퀘스트는 기본 목록에서 받는다 |
| Google Gemini | 구글 계정으로 받는 API 키 ([발급](https://aistudio.google.com/apikey)) | 무료 한도 안에서 0원 |
| Claude | Claude API 키 ([발급](https://platform.claude.com/)) | 일기 1건에 Haiku 약 10원, Opus 약 40~50원 |

- Gemini 무료 키는 보낸 내용이 구글 서비스 개선에 쓰일 수 있다.
- 키는 브라우저에만 저장되고 백업 파일에는 들어가지 않는다.
- 모델 이름이 바뀌어 오류가 나면 설정의 **모델 목록 불러오기**로 다시 고른다.

## 훈장·업적·칭호

- **훈장:** 기록관이 '이 사람에게 기념할 만한 날'이라고 판단하면 준다. 최근 2주 기록과 지난 훈장을 함께 보고 그 사람 기준으로 판단한다. 업적 포인트 동 25 / 은 50 / 금 100. 동·은은 7일에 한 번, 금은 언제든. 직접 판정에서는 내가 직접 훈장을 달 수 있다.
- **업적:** 일지를 쓸 때마다 5% 확률로 무작위로 찾아온다. 30번째 일지까지 안 나오면 확정. 이름은 기록관이 그날 일기에서 지어 준다. 업적 포인트 10.
- **칭호:** 훈장·업적의 이름. 보관함이나 이야기 카드에서 하나를 골라 이름 옆에 단다.
- **이야기 카드:** 훈장·업적을 누르면 그날의 일기, 기록관의 기록, 그때의 스탯이 열린다.
- 업적 포인트는 쓰는 돈이 아니라 쌓이는 점수다. 뽑기에 쓰는 건 아래의 '포인트'.

## 퀘스트·포인트·뽑기

- **집중 목표:** 일일·주간·월간마다 키워드를 정하면(예: 근력 운동 / 독서 / 자격증 취득) 그 주제로 퀘스트를 만든다. 비워 두면 최근 기록을 보고 만든다.
- **퀘스트 받기:** 기간마다 3개가 보이고 6개는 예비로 둔다. ↻로 바꾸면 예비에서 꺼내므로 AI 호출이 늘지 않는다. 예비가 떨어지면 그때만 새로 만든다.
- **난이도:** 최근 달성률이 40% 아래면 쉽게, 80% 위면 조금 어렵게 만든다.
- **달성:** 일지를 판정할 때 기록관이 퀘스트를 한 내용을 찾으면 자동으로 체크한다. 직접 체크해도 된다. 여러 번 해야 하는 퀘스트(예: 운동 3번)는 +1씩 오른다. 일지를 지우면 그 일지로 오른 진행도 되돌린다.
- **직접 추가:** 기간마다 최대 5개까지 내가 만든 퀘스트를 넣을 수 있다.
- **포인트:** 하루 첫 일지 +5P, 일일 +10P, 주간 +40P, 월간 +150P.
- **뽑기:** 1회 100P, 10회 900P(고급 이상 1개 보장). 일반 60% / 고급 28% / 희귀 10% / 전설 2%. 60번째 뽑기까지 전설이 안 나오면 확정.
- **조각:** 겹친 아이템은 조각이 된다(일반 5 / 고급 15 / 희귀 50 / 전설 150). 조각으로 아직 없는 아이템을 교환한다(일반 30 / 고급 90 / 희귀 300 / 전설 900).
- **아이템:** 가구·소품·반려동물·아바타 66종(이모지). 아바타는 이름 옆과 내 방에 보인다. 가구·소품·반려동물은 내 방에 놓는다.

## 내 방 꾸미기

- 캐릭터 탭 맨 위의 방. **꾸미기**를 누르면 편집 모드가 된다.
- **물건:** 가진 가구·소품·반려동물을 눌러 방에 놓는다. 같은 아이템을 2개 가졌으면 2개까지 놓을 수 있다.
- **훈장:** 받은 훈장을 벽에 건다. 꾸미기를 끝낸 뒤 벽의 훈장을 누르면 이야기 카드가 열린다.
- **배경:** 컨셉 배경 3종(🌳 마당: 하늘·해·울타리·잔디 / ☕ 카페: 벽돌 벽·칠판·펜던트 조명·체크 타일 / 📚 서재: 책장·벽 패널·벽등·러그)과 창문 있는 기본 방 5색(크림 원목, 하늘 타일, 민트 원목, 벚꽃, 밤).
- 물건은 끌어서 옮기고, 누르면 작게·크게·뒤집기·빼기를 할 수 있다. 아래쪽에 놓을수록 앞에 보인다.
- 아바타를 달면 방에 서 있고, 반려동물은 살살 돌아다닌다. 꾸미기를 끝낸 뒤 물건을 누르면 이름이 보이고 살짝 뛴다.
- 보관함의 아이템 창에서 **방에 놓기**, 훈장 이야기 카드에서 **방에 걸기**로 바로 놓을 수도 있다.

## 밸런스 조정

스탯과 숙련도, 포인트는 기록으로부터 매번 다시 계산하므로, 숫자를 바꾸면 과거 기록도 새 기준으로 다시 반영된다.

- `js/rules.js`: 강도별 경험치 `LM.INTENSITY`, 스탯 하루 상한 `LM.STAT_DAILY_CAP`, 레벨 필요 경험치 `LM.statNeed`, 숙련도 `LM.NOVELTY` `LM.OUTPUT` `LM.SKILL_TIERS`, 훈장 `LM.MEDAL_GRADES` `LM.MEDAL_COOLDOWN_DAYS`, 업적 `LM.ACHIEVEMENT_CHANCE` `LM.ACHIEVEMENT_PITY` `LM.ACHIEVEMENT_POINTS`
- `js/quests.js`: 퀘스트 보상 `LM.QUEST_KINDS`, 일지 보상 `LM.DIARY_POINTS`, 보이는 수·예비 수 `LM.QUESTS_SHOWN` `LM.QUESTS_PER_BATCH`, AI 없을 때의 기본 퀘스트 목록
- `js/gacha.js`: 확률·조각·교환 가격 `LM.RARITIES`, 뽑기 가격 `LM.GACHA_COST` `LM.GACHA_TEN_COST`, 천장 `LM.GACHA_PITY`, 아이템 목록 `LM.ITEMS`

## 파일 구조

```
index.html      화면 뼈대
css/style.css   디자인 (다크 모드 포함)
js/rules.js     게임 규칙·밸런스 숫자·경험치 계산
js/honors.js    훈장 그림(코드로 그림), AI 없을 때의 업적 이름
js/quests.js    퀘스트 기간 계산, 기본 퀘스트, 달성률
js/gacha.js     아이템 목록, 뽑기, 포인트·조각 계산
js/room.js      내 방 테마(벽지·바닥), 물건 크기, 처음 놓을 자리
js/db.js        브라우저 저장소
js/ai.js        AI 판정과 퀘스트 만들기 (Gemini, Claude), 지침
js/app.js       화면 그리기와 버튼 동작
```

## 휴대폰에서 쓰기

주소: **https://erudio-ludens.github.io/life-maker/** (GitHub Pages, 저장소 `erudio-ludens/life-maker`)

고친 내용을 사이트에 반영하려면 이 폴더에서 커밋한 뒤 `git push` 하면 1~2분 뒤 자동으로 바뀐다. 휴대폰에서는 앱을 껐다 켜면 새 버전이 열린다.

- 안드로이드(크롬): 주소를 연 뒤 메뉴 → **홈 화면에 추가**(또는 앱 설치). 앱처럼 전체 화면으로 열린다.
- 아이폰(사파리): 공유 버튼 → **홈 화면에 추가**. 아이폰 사파리는 7일 넘게 안 연 사이트의 저장 데이터를 지울 수 있어서, 홈 화면에 추가해서 쓰는 게 안전하다.
- PC에서 쓰던 기록 옮기기: PC에서 백업 파일 저장 → 휴대폰으로 파일 보내기(카카오톡 나에게 보내기 등) → 휴대폰 첫 화면의 **백업 불러오기**. API 키는 백업에 들어가지 않으니 휴대폰 설정에서 다시 넣는다.
